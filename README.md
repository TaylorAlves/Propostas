# AYIO — Proposta de Naming 2026

## 🎯 Sobre o Projeto

Este repositório contém a proposta estratégica de naming para a **AYIO**, um estúdio de software focado em inteligência artificial e impacto estratégico. O projeto foi desenvolvido como uma landing page interativa e minimalista que detalha a transição da marca antiga (Nexus) para a nova identidade verbal.

A proposta foca na convergência entre lógica computacional e resultados de negócio, utilizando uma estética "Ice & Ash" (Branco Gelo, Preto Profundo e Cinza Cinza).

## ✨ Funcionalidades

- **Diagnóstico Comparativo**: Gráfico interativo comparando os atributos de "Nexus" vs "AYIO".
- **Tese Semântica**: Desconstrução do nome (AI + Intelligence + Output).
- **Validação Técnica**: Argumentos sobre internacionalização e disponibilidade.
- **Mockup de Posicionamento**: Visualização da marca em um contexto de aplicação real.
- **Design Responsivo**: Adaptado para mobile e desktop com Tailwind CSS.

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **Semantic HTML**
- **CSS3** (Custom Properties e Layouts Modernos)
- **Tailwind CSS** (via CDN para prototipagem rápida)
- **Chart.js** (Visualização de dados)
- **Geist Sans** (Tipografia moderna da Vercel)
