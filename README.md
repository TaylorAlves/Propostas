# Proposta de Suporte Técnico e Operacional — Ciência, Coisa de Menina

Este repositório contém a proposta comercial estruturada em formato de landing page para o projeto **Ciência, Coisa de Menina**.

## 🚀 Tecnologias
- HTML5 / CSS3 (Vanilla)
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- [Geist Sans](https://vercel.com/font) (via CDN)

## 📄 Estrutura da Proposta
A proposta está dividida em 4 seções principais:
1. **O Desafio:** Diagnóstico da situação atual.
2. **A Solução:** Detalhamento do Onboarding e Manutenção Mensal.
3. **Conformidade:** Dados para editais e órgãos de fomento (CNPq).
4. **Investimento:** Proposta orçamentária e escopo de horas.

## 🛠️ Como visualizar
Basta abrir o arquivo `index.html` em qualquer navegador moderno.
